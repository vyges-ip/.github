# Vyges IP Catalog

**Open registry for silicon IP — metadata-first, machine-readable, free for the field.**

vyges-ip hosts the public mirror of the Vyges silicon IP registry. Each repo is a single IP block packaged with a consistent [`vyges-metadata.json`](https://vyges.com/technology/metadata-spec/) describing ports, parameters, dependencies, integration hints, and license terms. The index lives in [`vyges-ip-catalog`](https://github.com/vyges-ip/vyges-ip-catalog).

## Operator

vyges-ip is operated by **TrustStix Inc** (California, USA — C Corporation). The registry itself is free and open; operational costs (hosting, indexing, curation) are absorbed by TrustStix. We treat the catalog as public infrastructure for the silicon ecosystem.
